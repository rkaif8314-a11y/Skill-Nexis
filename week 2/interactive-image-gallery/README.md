# Lume Gallery — Week 2 Project

A responsive, interactive image gallery created for Skill-Nexis Week 2 (CSS + basic JavaScript).

## Open the project

Open `index.html` in a modern browser. The photographs and Google Fonts load externally, so an internet connection is needed for those assets.

## Features

- Eight photographs in a responsive CSS Grid.
- Hover zoom, subtle color treatment, gradient captions and animated arrow icons.
- Click any card to open a larger image in a native HTML dialog.
- Previous/next navigation, wrapping at both ends, image count and keyboard support.
- Escape-to-close, backdrop-to-close, descriptive alt text, visible focus and reduced-motion support.

## Skills practised

- **HTML:** semantic sections, descriptive alt text, buttons and a dialog.
- **CSS:** colors, typography, spacing, box model, grid, flexbox, hover states, transitions and responsive media queries.
- **JavaScript:** DOM selection, event delegation, event listeners, arrays, template strings, data attributes, keyboard events and DOM updates.
