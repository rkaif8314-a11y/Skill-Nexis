# Skill-Nexis — Week 2

**Topic:** CSS styling and basic JavaScript.

The assignment allows one main interactive project. The selected project is the **Interactive Image Gallery**. The separate CSS practice page covers all four questions from the practice set.

## Files

- [Interactive Image Gallery](interactive-image-gallery/index.html) — eight photos, responsive grid and interactive lightbox.
- [Gallery CSS](interactive-image-gallery/style.css) — layout, typography, box model, hover animations and responsive breakpoints.
- [Gallery JavaScript](interactive-image-gallery/script.js) — DOM selection, click events, lightbox navigation and keyboard controls.
- [CSS Practice Page](css-practice.html) — background and fonts, Flexbox centering, responsive three-column Grid and hover effects.
- [Gallery notes](interactive-image-gallery/README.md) — run instructions and assignment checklist.

## Run

Open `interactive-image-gallery/index.html` or `css-practice.html` in a browser. The photo URLs and Google Fonts are external assets and need an internet connection.

## Assignment checklist

- [x] Show 6–8 images in a grid (8 included).
- [x] Open clicked images in a larger lightbox.
- [x] Add hover animations.
- [x] Practice background colors, fonts, selectors and box-model spacing.
- [x] Demonstrate Flexbox centering.
- [x] Use responsive three-column CSS Grid.
- [x] Add hover effects to buttons, links and cards.
- [x] Practise DOM manipulation and event handling.
